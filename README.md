# QA Test Documentation – Incident Management Application

A QA test pack for a web and mobile health & safety (EHS) incident management application.

## What's inside
- **Login & Forgot Password** – test strategy and around 100 test cases (positive, negative, edge; UI, API and database), plus how SSO would change the approach
- **Incident Management** – system understanding and status flow, test strategy, end-to-end scenarios, detailed test cases with actual results, exploratory testing notes, bug reports with severity and priority, and screenshot evidence
- **Automation approach** – when to automate, what stays manual, and a phased plan (API, UI smoke, regression, mobile)
  
**Tested on:** https://qa-test.tenforce.info (QA environment)

## How to read it
Open `Senior_QA_Analyst_Assignment.xlsx` and start with the **Summary** sheet. It links to every section and shows the results.

## Tools and techniques
State transition testing, boundary value analysis, decision tables, risk-based prioritisation, exploratory testing, DevTools (network and performance), Postman, Playwright, Appium, BrowserStack, Jira / Zoho.
